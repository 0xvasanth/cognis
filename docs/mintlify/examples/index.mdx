Every example lives under [`examples/`](https://github.com/0xvasanth/cognis/tree/main/examples) in the repo. They're real, runnable programs — not snippets. Most work offline against fakes; a few need a provider key.

## How to run

```bash
git clone https://github.com/0xvasanth/cognis.git
cd cognis
cargo run -p cognis-examples --example <NAME>
```

For provider-backed examples, set `COGNIS_PROVIDER` plus the matching key. The simplest way is local Ollama — no key needed:

```bash
ollama pull llama3.1
COGNIS_PROVIDER=ollama COGNIS_OLLAMA_MODEL=llama3.1 \
  cargo run -p cognis-examples --example agents_react_agent
```

See [Environment variables](/reference/env-vars) for the full table of provider env names, and [Quickstart](/get-started/quickstart) for the smallest working agent.
