## How to run

```bash
# Offline (uses FakeEmbeddings):
cargo run -p cognis-examples --example retrieval_vector_store
cargo run -p cognis-examples --example retrieval_indexing_rag

# Provider-backed:
COGNIS_PROVIDER=ollama \
  cargo run -p cognis-examples --example retrieval_rag_pipeline
```

## Pick a starting point

- **First time touching RAG?** `retrieval_rag_pipeline` shows the full split → embed → store → retrieve → answer flow.
- **Re-indexing a corpus?** `retrieval_indexing_rag` covers incremental updates.
- **Improving retrieval quality?** `retrieval_cross_encoder` and `retrieval_document_transformers` are the post-processing layers.
