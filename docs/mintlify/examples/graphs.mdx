## How to run

Most graph examples are offline — they build typed state and run a small graph in-process.

```bash
cargo run -p cognis-examples --example graphs_state_machine
cargo run -p cognis-examples --example graphs_with_checkpoints
cargo run -p cognis-examples --example graphs_dot_export
```

## Pick a starting point

- **New to graphs?** `graphs_state_machine` is the simplest — counter that loops.
- **Need persistence?** `graphs_checkpoint_persistence` shows on-disk checkpoints.
- **Building human-in-the-loop?** `graphs_interrupts` is the canonical pattern.
- **Want to visualize?** `graphs_dot_export` produces DOT, Mermaid, and ASCII.
