Agent examples cover everything from a basic ReAct loop to multi-agent orchestration with custom strategies, planning middleware, lifecycle hooks, and pub/sub communication. Sources under [`examples/agents/`](https://github.com/0xvasanth/cognis/tree/main/examples/agents).

## How to run

```bash
COGNIS_PROVIDER=ollama COGNIS_OLLAMA_MODEL=llama3.1 \
  cargo run -p cognis-examples --example agents_react_agent

# Offline-friendly (uses fake provider):
cargo run -p cognis-examples --example agents_round_robin
cargo run -p cognis-examples --example agents_bus_pubsub
```
