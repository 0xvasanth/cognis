The numbered V2 demos are the fastest way to learn the shape of Cognis end-to-end. Each is a self-contained `.rs` file under [`examples/v2/`](https://github.com/0xvasanth/cognis/tree/main/examples/v2). All eight default to a fake or local Ollama provider, so they run offline.

## How to run

```bash
cargo run -p cognis-examples --example 02_five_line_agent
# or with Ollama:
COGNIS_PROVIDER=ollama COGNIS_OLLAMA_MODEL=llama3.1 \
  cargo run -p cognis-examples --example 06_ollama_tool_calling
```

## Recommended order

Read in number order if you want the full guided tour. If you're impatient, jump to whichever maps to your use case:

- **Building a chat agent?** → 02, then 06 for tools, then 07 for structured output.
- **Building a graph workflow?** → 01, then 03, then 05 for checkpoints.
- **Building multi-agent?** → 02, then 08.
- **Building a streaming UI?** → 04, then [Patterns → Streaming UI](/patterns/streaming-ui).
