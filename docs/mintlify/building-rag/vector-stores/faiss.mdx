Feature flag: `vectorstore-faiss`. Despite the name, there's no FAISS C++ library involved — the index implementations are pure Rust.

## Construct

```rust
use std::sync::Arc;
use cognis_rag::vectorstore::{FaissVectorStore, FaissConfig, FaissIndexType, FaissMetric};

let config = FaissConfig::new(1536)              // vector dimension
    .with_index_type(FaissIndexType::HNSW { m: 16, ef_construction: 200 })
    .with_metric(FaissMetric::Cosine);

let store = FaissVectorStore::new(embedder, config);
```

## Choosing an index type

| Index | Accuracy | Speed | Notes |
|---|---|---|---|
| `Flat` | Exact | Slow at scale | Brute-force. Good baseline, fine for small-to-medium corpora. |
| `IVFFlat { nlist }` | Approximate | Fast | Inverted-file index with k-means centroids. Trains on first `train()` call or implicitly once `nlist` documents are added. Tune accuracy vs. speed with `with_nprobe`. |
| `HNSW { m, ef_construction }` | Approximate | Fastest | Hierarchical navigable small-world graph — the standard production choice for large corpora. |

`FaissMetric` is `L2`, `InnerProduct`, or `Cosine` — pick the one matching how your embedding model was trained (most modern embedding APIs are cosine-similarity-oriented).
