Feature flag: `openai` (on by default). Default base URL: `https://api.openai.com/v1/`.

## Construct

```rust
use cognis_llm::provider::openai::OpenAIBuilder;

let provider = OpenAIBuilder::default()
    .api_key(std::env::var("OPENAI_API_KEY")?)
    .model("gpt-4o-mini")
    .organization("org-123")   // optional
    .timeout_secs(60)          // optional
    .build()?;
```

Or via env: `COGNIS_PROVIDER=openai`, `COGNIS_OPENAI_API_KEY`, `COGNIS_OPENAI_MODEL` — see [Environment variables](/reference/env-vars). There is no built-in default model; `model(...)` is required.

## Builder methods

| Method | Notes |
|---|---|
| `api_key(key)` | Required. |
| `model(name)` | Required — no default. |
| `base_url(url)` | Override for proxied or self-hosted OpenAI-compatible endpoints. |
| `organization(id)` | Sets the OpenAI-Organization header. |
| `extra_header(k, v)` | Add arbitrary headers. |
| `timeout_secs(s)` | Per-request timeout. |

## Wire format notes

- Tool calls surface as OpenAI's native `tool_calls` field and are normalized to Cognis's `ToolCall` on the way in.
- Streaming uses the standard `[DONE]`-terminated SSE stream.
- Auth is a standard `Authorization: Bearer` header.
