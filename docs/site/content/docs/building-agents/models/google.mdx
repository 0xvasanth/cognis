Feature flag: `google`. Default base URL: `https://generativelanguage.googleapis.com/v1beta/`.

## Construct

```rust
use cognis_llm::provider::google::GoogleBuilder;

let provider = GoogleBuilder::default()
    .api_key(std::env::var("GOOGLE_API_KEY")?)
    .model("gemini-2.0-flash")
    .build()?;
```

Or via env: `COGNIS_PROVIDER=google`, `COGNIS_GOOGLE_API_KEY`, `COGNIS_GOOGLE_MODEL`.

## Builder methods

| Method | Notes |
|---|---|
| `api_key(key)` | Required. |
| `model(name)` | Required — no default. |
| `base_url(url)` | Override the API base. |
| `extra_header(k, v)` | Add arbitrary headers. |
| `timeout_secs(s)` | Per-request timeout. |

## Wire format notes

- **Roles are `user` and `model`**, not `assistant` — Cognis maps this for you.
- **System instruction is a top-level field**, not a message in the array.
- **Tool calls are `parts[].functionCall`** (`{name, args}`); results go back as `parts[].functionResponse`.
- **Auth is `x-goog-api-key`**, not an `Authorization` header.
